# Uni-Sofus-Kalender

Kildekode til projektgruppens kalender. Den kørende hjemmeside hostes i Sites, og kalenderens data gemmes i en separat database. GitHub indeholder kildekoden; ændringer i GitHub udgives ikke automatisk til hjemmesiden.

Adgangskode og øvrige hemmeligheder gemmes som miljøvariabler og er ikke inkluderet i dette repository.
